東大前駅は東京大学弥生キャンパスの正門前に位置しているが、実際には南にある本郷キャンパスまでいくらか距離がある。とはいえ、上京したばかりの頃は、「東大前」という三文字を目にしただけで、当然のごとく寮からここまでの通学定期券を買ってしまった。そうして訳も分からぬまま一学期を過ごしてしまい、ようやく後になって気づいたのだが、実は丸ノ内線の本郷三丁目駅の方がはるかに便利だったのである。
研究科の自分の席よりも、東大前駅は学校の図書館にいくらか近い。学部生の頃は図書館で自習するのが好きで、いつも閉館まで居座っていたものだ。『かっこうワルツ』の物悲しくも穏やかなメロディに送られて図書館の門を出るたびに、充実した一日を過ごせたと、ひそかに誇らしく思ったものである。しかし東京に来て大学院生になってからというもの、図書館の閉館する場面にはとんとお目にかからなくなった。おそらく、夜も更けた東大前一帯があまりに寂しく、異郷にある者の孤独が、がらんとした通りにひっそりと響いているからだろう。雲一つない月夜など、あたりは物音一つなく静まりかえり、まさに「月影落ちて 鈴虫鳴く 思えば遠し 故郷の空」の寂しい感じになる。
それ故だろうか、東大前という土地は、私の記憶の中でいつも放課後の夕暮れと分かちがたく結びついている。工学部14号館のエレベーターホールから窓の外を眺めると、秋の午後の柔らかな日差しが、本郷通り西側にある二階建ての小さな書店の背後から差し込み、歩道をプラタナスの落ち葉の濃い黄色に染め上げる。それが研究室のインクの匂いとほのかなコーヒーの香りに混じり合うと、その雰囲気はいつも、高校時代に好きだった初音ミクの曲、『夕日坂』を思い出させるのだった。
14号館の下には、こんもりと葉を茂らせた一本の銀杏の木がある。夕陽は幾度となく、そして年々歳々、同じ金色にその葉を染め上げてきた。またしても東大前駅を通り過ぎ、学生時代の終わりに立ち尽くすと、背後にもまた、銀杏落葉色の夕日が差しているような気がした。
