清澄庭園は隅田川東岸の深川に位置し、東京の下町に属する。江戸時代には庶民が集う場所であった。とはいえ、街並みは文京に劣らぬほど静かで整然としており、地震時の土壌液状化を度外視すれば、住みやすい場所であろう。
清澄庭園の名を初めて耳にしたのがいつだったかは思い出せないが、この名前は記憶の片隅にそっと居場所を占める、そうした類のものだ。神道は「清」を尊び、禅宗は「澄」を好む。「清澄」の二文字だけで、日本文化の精髄がそこにあると言えよう。
「バラはバラと呼ばれなくとも、その香りは変わらない。」たとえ別の名前であっても、清澄庭園の雅致は変わらない。これは典型的な回遊式庭園で、中央の池が小島を囲み、景観は宮城県の名勝・松島を模している。南岸から眺めると、近景の松の枝、対岸の大正記念堂、そして遠方のスカイツリーが、階層的な美しい景色を成している。
回遊式庭園の設計目的の一つは、訪れる遊人に庭園の美を味わわせることにあるとされる。しかし、遊人自身に美意識がなければ、庭園の美も三分の一は色あせてしまうだろう。着物で鑑賞するのは格別だが、ビジネスカジュアルではやや堅苦しい。東京に来たばかりの頃、チェックのシャツを着て各庭園をうろついていたのを思い出す——今となっては、考えられない恥ずかしいことだね。
どこかで読んだことがある。「他の事柄の意味を考えがちな人は、逆に庭園の意味を理解しにくい」という言葉を。確かに庭園の意味について深く考えたことはないが、おそらく深く掘り下げる必要のないものなのかもしれない。午後の清風に松籟が響く。それだけで、十分な意義である。
