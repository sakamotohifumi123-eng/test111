前日、友人を訪ねて駒場へ出向いた。聞くところによると、東大の駒場キャンパスでは毎年11月に学園祭が催されるそうだが、本郷キャンパスの五月祭と同様、一度も足を運んだことがない。一つには当時自分のことで忙しかったから、もう一つには、そもそも大学院からようやく東京に来た身であり、何も学部生たちの賑わいに加わることもあるまいと思っていたからだ。
地図を見ていると、前田侯爵家の洋館が駒場キャンパスのすぐ隣にあることに気づいた。前田家は加賀藩の藩主で、「加賀百万石」の名で知られる。以前金沢を旅した際、北陸という辺境の地にありながら、その文化の雅やかさは京都に劣らないと感じたことがある。今回はちょうど通りかかったのだから、見学に立ち寄らない理由もない。
洋館は駒場公園の中にあり、黄色と白を基調とした配色は、東大工学部3号館を思い起こさせる。実のところ、前田侯爵家と東大とは浅からぬ縁がある。よく知られているように、東大の本郷キャンパスはかつて前田家の江戸屋敷であり、そのため前田家の遺した赤門は今や東大の象徴となっている。前田家が駒場に移り住むことになった経緯はといえば、関東大震災の後、東大の建物の多くが損壊し、増築用の土地を侯爵家から得たいと望んだことにある。その代わりとして、東大は駒場にあった農学部の敷地を前田家に譲り、新居の地とした。この因縁と関係があるのかどうかは分からないが、侯爵家の新邸も東大建築学科の教授の設計によるものである。
当時の当主・前田利為侯爵自身はドイツとイギリスに留学した経験を持ち、当時の日本には外国からの賓客をもてなすにふさわしい洋館が乏しいことを痛感していたという。そこでヴィクトリア朝時代のイギリスの荘園建築を模して、新居を建てたのである。侯爵は大正期の全国長者番付で第7位に名を連ねる富豪であり、また文化の粋を集めた加賀藩の藩主でもあった。その邸宅の内装が贅を尽くしたものであることは言うまでもない。もっとも、私は建築や室内装飾の専門家ではないので、僭越ながらあれこれと評するのは控えておきたい。
前田利為侯爵は、いわば落日の残照のような時代を生きた人だった。ヨーロッパにおいて「長い19世紀」はサラエボの銃声とともに幕を閉じたが、極東の日本では、その時が訪れるのに二十数年遅れることになる——ちょうど太陽が消えてから、その最後の光が地球に届くまでに8分かかるように。侯爵は、ヨーロッパ大陸にいる旧知の友人たちが、1930年代に自分の娘をアメリカの成金に嫁がせたことを、どのような思いで見ていたのだろうか。その光景はあるいは、オルレアン朝時代のハプスブルク家が、ナポレオンによって叙爵された新興貴族を眺めたときの心境に似ていたのかもしれない。
侯爵は1944年、カリマンタン島（ボルネオ島）で世を去った。時代の波は、彼が世を去った後になってようやくその一族を捕らえた。前田侯爵邸は米軍航空司令官の官邸となり、壁に貼られた金唐革紙は剥がされ、煙突を通すために屋根まで開けられてしまった。
2018年、侯爵邸は修復を終え、一般に公開された。すべてが元通りになったかのようだった。帰り際、案内を務めていたご婦人に、この邸宅をどう思うか尋ねられた。私はこう答えた。「すべてはとても素晴らしいです。ただ、侯爵はもういないのですね。」
