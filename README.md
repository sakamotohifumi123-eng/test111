
       不同的人扮演不同的角色，扮演舆论领袖和知识分子这种角色的人极少能在政治上有什么成就。他们都是在太平盛世的时候在自我陶醉中过日子，在乱世的时候基本上是第一批被淘汰的，就是因为他们原有的博弈习惯使他们不能适应新的环境。例外是极少数，例如像伊斯兰世界的哈查只·伊本·尤素福这样的小学教师。他到库法的清真寺中去，看到了什叶派和逊尼派双方之间的尖锐对立，也看到了阿里的支持者对大马士革哈里发政权的极度仇恨和他们在军事上又缺乏准备的狼狈状态。他就说出了这样的话：“库法的人民啊，我看到你们的头巾和下颌之间热血在流，我看到无数的头颅像是田野中的麦穗一样已经黄熟待割。”他说这句话的意思是，你们要么不要反对大马士革的哈里发，要么如果你们反对他的话，你们这些阿里派就要做好军事准备。你们两者都没有做，又要跟别人做敌人，又想忽视自己保卫自己的义务，我看你们马上就要完。然后他就投入了大马士革哈里发的军队当中，杀到伊拉克去，最后做上了伊拉克总督。按他的出身来说，只是一个小知识分子，但是他最后没有落在那些被杀的人当中，而且还变成了那些被杀的人的统治者，是因为他首先有这样的判断，事后又能改变自己的身体习惯，在乱世当中出人头地。
        所以，选择权都是在个人的。首先要分析清楚形势，形势分析清楚以后，根据相应的形势尽可能地争取最好的结局就行了。不要去抱怨形势本身，形势不是你能够左右的。没有哪个农民能够到处去抱怨天气怎么样或者自己的田地怎么样，有些东西是先天的和不可能改变的条件。要有智慧去分清什么是不可改变的事情，要有抓住时机的判断力去改变那些你可以改变的事情。其他的东西说得太多或者关心得太多，都是集邮爱好者浪费时间的做法，现在已经不是集邮爱好者能够混得下去的时间了。
