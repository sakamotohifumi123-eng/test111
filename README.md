都内数ある桜の名所の中でも、いち早く花期を迎えるのが神田川である。人の性というものであろうか、名の知れた観光地であっても、いざ身近にあるとかえって格別な感慨を覚えぬものらしい。ただこの頃、家の近くが遊人で賑わうのを見るにつけ、心のうちにひそかな誇らしさが湧いてくる——「里仁為美、択不処仁、焉得知」（仁に里るを美と為す。択びて仁に処らずんば、焉んぞ知なるを得ん）。

関東の春はとかく雨がちであるが、三月末の花見どきに巡り合わせると、日頃はいささか鬱陶しい雨も、かえって一興となる。雨滴が枝や花びらに宿り、もとより淡紅白の染井吉野に透き通るような質感を添え、いくばくかの空霊たる趣を醸し出す。傍らの神田川のせせらぎの音とあいまって、目の前の景色はさながらあの有名な浮世絵「墨田堤の花見」を思わせる。もっとも、今の墨田川の両岸は高層ビルが立ち並び、当時の景観はもはや跡形もない。

そばの山紅葉の若葉もまた興趣に富む。あの生き生きとした緑は、日本の子供たちが背負う蛍光色のランドセルさながらで、真紅の蕾を点々とあしらい、春の新緑の中でひときわ目を引く。山紅葉も桜も、幹には苔がびっしりと生し、雨に十分水気を含んで、いくぶん古雅な趣を醸している。

神田川は江戸時代に開削された運河で、今日に至るまで四百年余りの歴史を持つ。聞くところによれば、六十年代に首都高速道路が建設された折、都内の用地不足のために、楓川や築地川などはやむなく埋め立てられ、道路用地に充てられたという。しかし神田川は幸いにも埋め立てを免れ、江戸の面影を今に残す貴重な存在となった。今の神田川は首都高速道路と隣り合い、高架橋が川の南岸にぴたりと寄り添っていて、それが桜の背景となっているのもまた一興である。

いつか文京を離れることがあれば、この神田川の桜を懐かしむこともあろう。以前、とあるお寺の前を通りかかった折、門前の掲示板に興味深い言葉が貼られているのを見た。「ありがとうの反対語は何？」——答えは「当たり前」。雨の中に散る桜を眺めながら、ふとこの言葉を思い出したのであった。
