墨田区のスカイツリーに一番高い建物の座を奪われたとはいえ、東京タワーはいまもこの街のシンボルであり続けている。港区の高層ビル群の中に映える紅白の華やかな配色は、昭和時代の素朴な美しさもこんなに愛おしいものだと、あらためて気づかせてくれる。

御成門の近くの会社でしばらくインターンをしていた。東京タワーはオフィスのブラインドの向こうに、ただ静かにそびえていた。曇りがちな午後、陽光が雲を突き破って塔身に降り注ぐと、くっきりと対立していたはずの紅と白が、柔らかなオレンジ色の光の中でそれぞれの鋭さを和らげていく。ちょうど仕事が片づいたあとであれば、ゆったりとホットココアをひと口すする、まさに至福のひとときだった。

もっとも、今に至るまで東京タワーに登ったことはない。会社からあまりに近すぎて、観光する気持ちをすっかり失ってしまったせいだろう。けれど仮に本当に頂上まで上って四方を見渡せば、スカイラインには煌めくガラスのカーテンウォールを纏った超高層ビルばかりが並び、この落ち着きの中に躍動感をたたえた建物の姿がそこにない――それはやはり少し寂しいことだと思う。

入社前夜の深夜、あれこれと思い巡らせて眠れずにいた。故郷の柳、近春園のハナズオウ、神田川の桜、そして東京タワーの鉄骨が、頭の中でひとつに混ざり合っていた。人生の節目というのは、きっとそういうものなのだろう。そのとき、ふとセネカの一句が思い出された。「望む者を、運命は導く。望まぬ者を、運命は引きずっていく」。本当にそうなのかもしれない。
