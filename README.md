お台場はかつて、江戸時代末期に欧米列強の上陸に備えて築かれた海上砲台である。しかし時代は移り変わり、かつて厳重に守られた要塞は今日の公園へと姿を変えた。レインボーブリッジのたもとに、人工島の城塞のような基盤だけが、往時の物語をひっそりと伝えている。

都会の日常からほどよく切り離されたこの場所は、格好の憩いの場でもある。修士課程の頃、同期のひとりが暇を見つけては海浜公園で夕日を眺めるのを好んでいたことを思い出す。銀白のレインボーブリッジも黄昏時には古いフィルムのような温かみを帯び、新橋の高層ビル群が地平に静かに佇む中、穏やかな東京湾の沖合を行き交う小舟が日の出桟橋に寄り添うように着く――それはなんとも風情のある眺めだったことだろう。

フジテレビの本社は台場の北岸、海浜公園のすぐ隣に構えており、球形の展望室がひときわ目を引く。ここから南に目をやれば、遠くにゲートブリッジ、さらにその先に羽田空港がうっすらと見渡せる。一分に一便の飛行機は、いったいどれほどの人々の夢を乗せているのだろう――当時、遠い水平線を眺めながらそんなことを考えていた。

去年の三月、インターンの縁で東京ビッグサイトで開かれた再生可能エネルギーの展示会に参加したことを今も覚えている。仕事を終えて帰路につく途中、ゆりかもめの最後尾に腰を落ち着け、淡い青からオレンジ色へとなだらかに移ろう空を眺めていた。春にしては少し肌を刺す潮風が夕陽とともに吹き寄せてきたとき、ふとそこに言葉では言い表せない趣があることに気づいた。おもむくままに一句詠んだので、読者のご批評を賜われれば幸いである。

一昨年、空母「プリンス・オブ・ウェールズ」が来日した際には、お台場に静かに停泊し、見物客の写真撮影に応じていた。この地の歴史と、もう一隻の「プリンス・オブ・ウェールズ」がたどった運命とを思い合わせると、世の移ろいの激しさに、感慨を禁じ得ない。
