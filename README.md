小金井公園は、舎人公園や神代植物公園などとともに、1930年代後半に策定された「東京緑地計画」によって整備された公園地帯の一つです。
当時の内外情勢が戦雲に覆われていたことを思えば、こうした計画が比較的順調に進められたことは、一見すると驚くべきことに思えます。しかし、時代精神を丁寧に汲み取ってみれば、当時の世相と符合していた点も理解できないわけではありません。極東の時計は西欧より二拍遅れていたのかもしれず、東京の都市計画は、ナポレオン三世によるパリ改造計画の遠い残響に過ぎなかった可能性もあります。いずれにせよ、都市工学者の良いとは、小さな確かな幸せを求める人々にとっては悪い日でもあるのです。
公園は1940年に着工し、ちょうど紀元2600年祝典の時期にあたりました。偶然にも、この祝典のために建てられた光華殿が、後年ここに移築されています。小金井公園は開園後も幾度となく変遷を重ね、戦時中は文部省管轄の「国民錬成所」として利用されました。目白校舎が空襲で大きな被害を受けたため、戦後の一時期には学習院の仮校舎としても使われました。1993年には、歴史的建造物を保存・活用する目的で屋外博物館「江戸東京たてもの園」が開設され、光華殿は博物館のビジターセンターとして生まれ変わりました。
殿の前に立ち南を望むと、遊歩道は木々の奥深くへ静かに消え、道の両側には青々とした芝生が広がり、散策や憩いに訪れた人々が点在しています。これが当初の計画者たちの願いを、ようやく叶えた姿なのかもしれません。しかしこの風景は、ふと奈良の平城宮跡を想起させます。
おそらく唯一変わらないのは、この地の桜でしょう。江戸時代から小金井は城西の花見の名所として知られ、今も花見の季節になれば大勢の人で賑わいます。百年もの間、周囲の景色は激しく移り変わっても、春に舞う桜吹雪の情景だけは昔のままです。桜の散りやすさを見ては、世人は物の哀れや無常を嘆きますが、実は人事の無常こそ、桜以上に儚いものなのかもしれません。
