3月の風物といえば、卒業、桜、そして確定申告である。税務署から届く納付書を手にすると、どうしても物哀れな気持ちにさせられる。先日、東京国税局に確定申告に出向いたついでに、近くの浜離宮恩賜庭園にも足を運んでみた。

「離宮」と「恩賜」の二言で、この地の格式の高さは推して知るべしである。かつては宮内省の管轄下にある皇室用地で、迎賓館として、来日したグラント元米国大統領を迎えたこともあるという。当時の浜離宮は、さしずめ今日の赤坂迎賓館さながらに、警備の厳重な高嶺の花だったに違いない。もっとも、離宮の建物の多くは戦火で失われてしまい、今となってはその頃の面影を偲ぶことはできない。

大手門をくぐって、まず目に入ったのは一面の菜の花畑で、なんとなく故郷の田園風景を思わせた。ちょうど花の盛りで、時折、金色の花畑の中に佇む観光客の姿も見受けられた。なぜだかは分からないが、菜の花は浜離宮の雰囲気とはどこかそぐわない気がしたし、背景にそびえる汐留の高層ビル群とも、いまひとつ調和していないように感じられた。ふと、『万葉集』で読んだあの短歌が思い出される。

世の中を 常なきものと 今ぞ知る 奈良の都の うつろふ見れば

千年前、この歌を詠んだ人が目にしたのも、あるいはこれと似たような風景だったのかもしれない。拙いながら、一句詠んでみたので、お目汚しにどうぞ。

菜の花や　松風の音　浜離宮

さらに奥へと進むと、池が一つ見えてくる。日本庭園の定番といったところだろう。池のほとりの松は、他所のものとは趣が異なり、枝ぶりが実に丹念に手入れされていて、その形はさながら中学の理科の実験で使う試験管ブラシを思わせ、なかなかに興味深い。池に架かる木橋も一風変わった趣があり、桟橋のような造りで、海辺に位置するこの浜離宮という庭園にはよく似合っている。

もっとも、浜離宮で最も目を引くのは、実は庭園の外にある。緑色のガラス張りの高層ビルで、屋上には「CONRAD」の文字が大きく掲げられている――コンラッド東京のビルである。湾岸に立ち並ぶ数多の高層ビルの中にあってもひときわ存在感を放ち、訪れる者の視線を、松の葉や水の流れから否応なく奪ってしまう。とはいえ、かつての赤坂プリンスホテルのように、この少々目障りな建物を取り払ってしまえば、遠景はどこか物足りなく、がらんとしたものになってしまうのだろう。既成事実というものは、いかんともし難いものである。
