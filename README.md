神保町は東京における文化人の中心地である。ここには確かに古書店が数多く軒を連ねており、以前通りかかった折には、古書市の催しに行き合わせたこともあった。もっとも、私自身はこの手のものにはさほど興味を持たない。文化人と言えば、どうしてもウィーンやパリのカフェにおける清談を思い起こさせる。そこに集う者たちは、少なくともツヴァイク氏やジョフラン夫人と同座するに値する人々であったろう——恐れ多いことに、私などはとてもその末席に連なる資格はない。
神保町を初めて訪れたのは、まだ一昨年、東京に来たばかりの頃であった。就職支援講座を聴きに行ったのである。なぜこの土地が会場に選ばれたのか分からないが、今にして思えば、就職活動というものほど、この街の精神から懸け離れたものはあるまい。書店に浸っている人々の心の中には、いつまでも卒業しない学生がずっと生き続けているかのようだ。アリストパネスが風刺した「雲中国」の住人よろしく、形而下の俗世が自分たちのイデアの世界を汚すのを恐れているかのようである。

東京には有名な中国語書店が二軒ある。一つは「単向街」といい、銀座にある。もう一つは「局外人(アウトサイダー)」といって、こちらは神保町にある。両者の間には、当然ながら微妙な気質の違いがある。とはいえ周囲の社会から見れば、それはまるで日本を訪れたことのないウルグアイ人に、京都人と大阪人のごく些細な違いを論じさせるようなもので、いささか的外れな話でもあろう。いわゆる「コップの中の嵐」というやつで、まあ放っておくに越したことはない。

単向街書店ではコンサルティング業界に関する講演を一度聴いたことがあり、また近くのレストランでとても美味しいカレーを食べたこともあった。それ以来、神保町へは一度も足を運んでいない。そまみちはすでに分かれ道を過ぎ、振り返れば、知識人の歩む小径は、はや視界の彼方へと消え入りつつある。
