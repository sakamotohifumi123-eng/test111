
       六月の東京は、梅雨の季節を迎えた。どんよりと曇った空が続くと、どうにも外へ出る気が起きない。金曜日、同僚と雑談しながら「週末もまた雨とは困ったものだ」とぼやいていたら、「それなら紫陽花を見に行ってはいかがですか。梅雨といえば、紫陽花の季節ですから」と勧めてくれた。その言葉を聞いて、思わず心が明るくなった。——さすがは清少納言を生んだ国だと、ひそかに感じ入った。
折しも週末は都外へ出る用事があった。常磐線の北小金駅の近くに本土寺という古刹があり、紫陽花の名所として知られているという。ちょうど見頃とあれば、立ち寄らない理由などない。山門をくぐると、まず目に飛び込んでくるのは、五重塔の裾を彩る花の群れだった。藍色の花冠が、霧雨と微風の中でほんのりと揺れ、木塔と相映えてなんとも愛らしい。しかし、ここだけの紫陽花では、「名所」の名に応えるには少し物足りないかもしれない。本堂の脇にひっそりと続く小道があり、腰をかがめて低い門をくぐり抜けると、本土寺の裏山へと出た——紫陽花の真髄は、実はここにあったのだ。
裏山の竹林を抜けると、目の前に菖蒲園が広がった。紫陽花とともに、六月の本土寺を一層引き立てている。なかでも最も見応えがあるのは、弁天池に浮かぶ小島だった。岸辺の藤棚からそちらを眺めると、手前の山もみじの若葉、池に漂う睡蓮、そして遠く島上に立つ仏堂が、重なり合いながらも絶妙の間を保っている。松尾芭蕉の名句「古池や 蛙飛びこむ 水の音」が目の前に具象化されたかのようだ。それだけでも精緻な夏の一幅であるのに、さらに仏堂のそばで胸に染み入る淡い青が目に留まる——言うまでもなく、紫陽花である。「梅子黄時雨」の関東郊外は、みずみずしい翠緑を基調とし、終日デスクに向かう都会人にとって、またとない憩いをもたらしてくれる。けれども、紫陽花の彩りがなければ、やはりどこか単調に映ってしまうのではないだろうか。
藤棚の下にしばらく佇んでいると、雨が少し強くなってきた。唐の玄宗が八重の桃の花を一枝折り、楊貴妃に手渡しながら「この花は、あなたの美しさをいっそう引き立てる」と言ったという故事が、ふと頭に浮かんだ。傍らには、ちょうど濃いローズ色の紫陽花が一株——花びらに雨粒をためて、しとやかに佇んでいる。「楊妃の助けなど借りずとも、初夏ではこの花がいちばんだ」。雨の中、そんなことを思った。
