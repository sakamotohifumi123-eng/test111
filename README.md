2月はちょうど湯島天満宮の梅の見頃で、参拝客もおのずと群れをなしていた。もっとも、ここの梅はさほど見事というわけでもなく、本殿の南側、小さな池のほとりで人工の滝のせせらぎに寄り添うように咲く数株だけが、いくらか趣を感じさせる程度だった。
湯島天満宮がこうして梅の名所となったのは、おそらくご祭神・菅原道真公にゆかりがあってのことだろう。道真公の家紋は梅だったのである。伝説によれば、彼は朝廷で藤原氏の恨みを買い、九州の大宰府へ左遷され、失意のうちに世を去って怨霊になったという。ちょうど古代中国の災を司る趙公明が財神として祀られるようになったのと同じように、菅原道真もまた、民間の信仰の中でいつしか「学問の神様」へと姿を変えていったのだろう。そして梅の咲く季節は、日本の学生たちが受験に臨む時期とちょうど重なるため、参拝客が引きも切らないのも当然のことだ。境内に掛けられた絵馬も壮観で、「試験合格」「学業成就」といった願いごとがびっしりと並んでいる。
そう遠くない上野公園には、「上野合格大仏」という仏像もある。この時期はきっと、こちらも参拝客で賑わっていることだろう。武士の末裔たちがこぞって受験勉強にいそしむ姿を目にすると、思わず苦笑してしまう。世の移ろいとは、こういうことなのかもしれない。
