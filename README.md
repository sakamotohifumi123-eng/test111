それは二年前の秋のことだった。まだ新学期が始まる前で、気だるい日常のひとときが殊のほか貴重に感じられる頃合いだった。ある日の昼下がり、ふと思い立ち、目白台の寮から歩いて学校まで自習に向かい、ついでに道々の街並みでも眺めてみようと考えた。それはなかなか面白いことに思われた。
思い立ったが吉日である。お茶の水女子大学の南側の坂を登り、教育の森公園と小石川植物園の北側に広がる閑静な住宅街を抜けると、白山神社に至る。平日の午後とあって、さして広くもない境内には自分ひとりきりだった。初秋の日差しが本殿の緑青色の屋根に降り注ぎ、傍らの青々とした草木までもが、心なしか淡い黄色を帯びているように見えた。
なかなかによい景色ではあったが、周りの他の寺社と比べて、これといって特筆すべきところがあるわけでもない。白山神社にしばし佇んだのち、あとはひたすら南へ向かえば、学校に着く。本郷通り沿いの看板は、秋の空気によく似合う、古びたフィルムのような暖色を帯びていて、なんとも心の休まる雰囲気だった。研究室に着くと友人もおり、お茶を淹れて語らった。「安穏」という言葉を具体的な情景で表すなら、まさにあの時あの場所をおいて他にあるまい、と今でも思う。
日常の生活圏からあまりに離れているせいか、卒業してからというもの、白山あたりには一度も足を運んでいなかった。白山神社は、あの日の午後の暖かな日差しとお茶の香りとともに、いつしか否応なく「昨日の世界」の一部となってしまったようだった。ところが先日、都内であじさいを見に行ける場所を調べていたところ、リストの一番上に、思いがけず「白山神社」の文字があった。なんと、あの小さく目立たぬ神社こそが、「文京あじさいまつり」の開催地だったのである。
そこで喜んで足を運んでみた。境内は人でごった返しており、あの秋の日の静けさとはまるで別世界だった。正殿の入り口にあった、かつては何の変哲もない「植え込み」だった一角が、今では薄い水色の海と化していた——言うまでもなく、あじさいである。梅雨の時期だというのに、あじさいと古びた木造建築とが、なんとも不思議な涼やかさを醸し出していた。時折、着物姿の観光客がそぞろ歩きながら眺めている様子は、まさに極上の夏の一幅の絵であった。
帰り際、神社の入り口に、あじさいの茂みにひっそりと隠れるようにして石碑が佇んでいるのに気がついた。目を凝らしてみると、それは何と孫文先生の記念碑だった。聞けば、明治43年（1910年）五月中旬のある夜、孫文先生は盟友・宮崎滔天氏とともにここで中国の未来を語り合ったのだという。それゆえ、この地に碑が建てられ、記念とされたのだそうだ。あの夜の白山神社にも、今日と同じようにあじさいが咲き誇っていたのだろうか。碑の前に立つと、ふとカエサルが若き日にアレクサンドロス大王の像を見て、自らの功業の未だ成らざるを嘆き、涙したという故事が思い出された。私は一つ深く息をつき、踵を返してその場を後にした。
