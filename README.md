奈良の北部は、いつ訪れても観光客でごった返している。東大寺、奈良公園、春日大社——どこも肩がぶつかり合うほどの賑わいだ。景観そのものはたしかに一見の価値があるが、あまりに人が多すぎると、いささか興ざめになってしまうのも否めない。
それならば、少し足を延ばしてみてはどうだろうか。近鉄線に沿って南へ下っていくと、橿原市に着く。伝えるところによれば、ここは二千年以上前、九州の日向国から東征してきた神武天皇陛下が即位された地であるという。日本史における神武天皇は、さながら中国史における黄帝のような存在で、伝説と史実とが幾千年にもわたって絡み合い、想像と真実の境界を曖昧にしている。そもそも上古の伝説というものは、その本質からして神話と分かちがたく結びついているものであり、こうした伝説を合理化しようとするいかなる試みも、「金魚を水ごと桶から捨ててしまう」危うさを孕んでいる。そのうえ、無味乾燥な資料をいくら並べ立てたところで、人間本来の畏敬の念を呼び起こすことなど到底できはしない。ジャンヌ・ダルクとロレーヌ十字の伝説は子供の教育にうってつけの題材だが、ヴェイガン将軍やジョッフル将軍の巧みな用兵術となると、そうはいかないのである。
神代の昔は悠遠にして考証しがたいものだが、橿原神宮の境内を少し歩いてみれば、懐古の情を誘われることだろう。神宮は初代天皇を祀るために建てられたものとはいえ、実際に造営されたのは1890年のことで、おそらくは明治維新以降の国学復興・王政復古の気運に負うところが大きい。もっとも、神道の建築は仏教のそれとは異なり、もとより「新しさ」をこそ美とする。格式最高位の伊勢神宮でさえ、二十年ごとに式年遷宮を行っているのだから。境内の参道は玉砂利敷きで、ここは通勤路ではないのだと、いくらか歩みを緩めるよう促されているかのようだ。
橿原は奈良盆地の南に偏し、四方を山々に囲まれているため、桜の時季も東京よりいくぶん遅く、三月末になってもまだ満開には至らない。とはいえ、蕾をつけたソメイヨシノと本殿の青緑の屋根とは、なかなかによく映え合っている。神宮の南側にある小さな湖のほとりにも桜が一列に植えられており、もし折よく晴れた満月の夜にでも訪れれば、そよ風に花びらが湖面へと舞い落ち、遠く吉野の山々の稜線を望むさまも、さぞ美しいことだろう。そう思うと、つい阿倍仲麻呂のあの和歌が思い出されてくる。
