都電荒川線は、東京都内の他の電車とはまったく異なる。通勤客の姿はほとんどなく、乗客の大半は近隣の主婦や学生である。その雰囲気は、小学生のころ学習塾へ通う際に乗ったバスを、どこか思い起こさせる。
ここは都内に残る最後の路面電車路線である。だからこそ、乗車していると、レトロな雰囲気が自然と漂ってくる。このレトロ感は、沿線の街並みと見事に溶け合っている。荒川遊園地や飛鳥山公園など、沿線に点在する観光地はいずれも昭和の面影を色濃く残しており、まるで時間がゆっくりと流れているかのようだ。
荒川線は、のんびりとした路線である。観光を売りにしている点では小田急の「ロマンスカー」と共通しているが、その性格はまったく対照的だ。ロマンスカーは人波の絶えない新宿を起点に、これまた観光客で賑わう江の島へと旅客を最速で運ぶ。一方、荒川線は早稲田と三ノ輪のあいだをゆっくりと往復し、二分おきに「チリン、チリン」と鈴を鳴らす。まるで、旅の途中にも美しい景色があることを、わざわざ教えてくれているかのようである。
荒川線のホームとレールは、ストリートフォトグラフィーの格好の被写体である。プラットホームで電車を待つ乗客たちも、まるで映画のフィルムから抜け出してきたように見える。飛鳥山の近くでは、電車と自動車が並走する光景も趣深い。大塚あたりの線路では、春になると野の花が枕木の間の砂利に咲き、なんとも愛らしい。
一昨年の冬、荒川線に乗って千住へ観光に出かけたとき、NHK番組「美の壺」の音声が流れていた。将棋の駒の制作を取り上げた回だったように記憶している。ある職人が手がけた将棋盤の四本の脚に、クチナシの花の紋様が彫られているという話があった。その時初めて、梔子という花が日本語で「クチナシ」と読むことを知った。なんと美しい名前だろうと思った。あの日の千住の街並みはもうほとんど思い出せないが、午後の陽光が車内に差し込んでいたあの光景だけは、今もぼんやりと頭に残っている。車輪がレールを刻む「ガタゴタ」という音と、ドキュメンタリーの音声とが混ざり合い、真冬であるのに、車内にはどこかクチナシの花の香りが、ほのかに漂っているように感じられた。
