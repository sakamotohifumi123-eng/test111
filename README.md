丸之内は東京の中心で、天皇陛下がお住まいになる場所ですから、自然と格調が高いものです。北側の大手町は大手銀行の本社が集まる場所、南側の霞が関は国家機関がひしめくところ、どちらも少し畏まって敬遠したくなる雰囲気があります。東側の八重洲は、逆に生活感のある場所で、鉄道の高架橋の下には居酒屋やラーメン店が並んでいて、ここが皇居まで歩いてわずか5分ということをつい忘れてしまいます。

八重洲で1年半インターンシップをしていました。通勤や帰宅の道すがら、東京国際フォーラム（東京国際フォーラム）を通り過ぎます。かつての東京都庁舎です。内部から上を見上げると、平行に並んだ桁架がまるでクジラの肋骨のようで、歩く人は魚の腹の中を進んでいるかのようです。中ではさまざまな展示会がよく開催されますが、中に入って見学することはできません。ただ欄干の外から中をのぞき見るだけでも、とても興味深いものです。

会社の窓からは銀座の街並みが見え、さらに遠くには豊洲のタワーがそびえています。夕陽が沈む頃、ガラスの壁面や空の雲がオレンジ色に染まり、心が安らぐ景色です。

毎日窓の外は銀座の景色なのに、正直なところ銀座をあまり散策したことはありません。覚えているのは、「三丁目のカレー屋さん」というカレー屋さんがとても良かったこと。店名も雰囲気も、あの有名な映画『三丁目の夕陽』を連想させます。銀座の文具店・伊東屋で、高校に合格した従弟に進学のお祝いギフトを買ったし、ここであまり有名でない芸術家の展覧会も見たことがあります。それ以外はあまり記憶にありません。

東京駅はよく通ります。ここは赤レンガ造りのヴィクトリア様式の建物で、とても可愛らしいです。丸の内北口から駅に入り、見上げると天井の造りも趣があります。駅の2階に「とらや」という和菓子店があり、そこのかき氷や羊羹は格別です。

東京駅の正門は普段は閉じられていますが、各国大使が東京に赴任する際に開放されるそうです。宮内庁の馬車がここで待機し、大使を宮中へお連れするとのこと。この光景は耳にしただけですが、宮内庁馬車の訓練風景は実際に目にしました。訓練は皇居外苑で行われ、東京駅のちょうど向かいです。茶色の純血馬がフルハーネスを付け、毛並みをピカピカに磨かれ、二人の宮内庁職員が御者台に座り、澄んだ鈴の音を響かせながら、ゆったりと坂下門から出てきます。外苑の砂利道を一周し、のんびりと皇居に戻っていきます。

実は日本に来て間もない頃に一度丸之内を訪れたことがあります。それは修士課程の入学前でした。景色は今も変わりませんが、当時の心境は今とはずいぶん違っていたはずです。
