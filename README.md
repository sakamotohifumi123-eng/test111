根津から北へほど遠からぬところに千駄木がある。寺社の密集する土地柄である。折しも春雨の時節にでも行き合わせれば、杜牧の『江南春』にいくらか通じる趣もあろうか。日本に来たばかりの頃は、駒込のホテルに宿を取っており、学校までは電車で二駅の距離であった。ある日、本郷通りを歩いて学校へ向かった折、道すがら足早に千駄木を通り過ぎたことがある。今この土地への最初の印象を思い返してみても、文京の他の界隈と同じく、ただ静かな街区だという程度で、ここに独特の美があることには気づかずにいた。
再びこの地を訪れたのは、つい先日の夜のことである。ある先輩が使わなくなったトースターを譲ってくださるというので、千駄木で待ち合わせることになったのだ。早めに着いてしまい、待つ間あたりの街並みを眺めていると、通りに素朴な四角い街灯が点々と並んでいることにようやく気づいた。夜になると銀白の光を放ち、もとより人影のない通りを、いっそう静かに見せている。もっとも郊外の寂寞とは違い、道の両側には二、三階建ての民家が不揃いに立ち並び、静けさの中にもほのかな安心感を与えてくれる。
この界隈の桜もまた実によい。花見というものは本来、人が多く賑わってこそのものだが、夜が更ければまた別の話である。物音一つない夜の中で、花びらの散り落ちる音さえ聞こえてきそうな、それこそが夜桜の醍醐味というものだろう。聞くところによれば、このところ日本橋あたりでは桜のライトアップが催されているというが、それではどうも通俗に堕してしまう。千駄木のようなこの静かな夜でなければ、夜桜の美しさもまた成り立ちがたいのではないか。あるいは、塀際にひっそりと咲く桜が、この街区をいっそう静謐なものにしているのかもしれない。
ふと気づけば、すぐそばに森鷗外記念館があった。この軍医にして文豪であった人物が、後半生を過ごした住まいの跡である。森鷗外その人の気質もまた、あるいはこの千駄木という街区に溶け込んでいるのかもしれない——街灯の光の柱の下で、そんなことを思った。
